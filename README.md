# Distant Console

Автоматическое прохождение тестов на Moodle.

## Что это

Distant Console — программа для автоматического заполнения и сдачи тестов на платформе [ирбис-дистант.рф](https://xn----8sbbnrbc5bumdmc.xn--p1ai/my/index.php). Работает полностью автоматически: выбирает курс, открывает тест, заполняет ответы и отправляет на проверку.

## Возможности

- Автоматический вход на сайт
- Выбор курса и теста из списка
- Два режима прохождения:
  - **С ответами** — использует сохранённые правильные ответы
  - **Случайно** — заполняет случайными ответами и сохраняет правильные для следующего раза
- Поддержка всех типов вопросов: текст, выбор, перетаскивание, порядок, выделение слов
- Два интерфейса: упрощённый (без логов) и расширенный (с логами)

## Установка

1. Скачайте `Distant.exe` из [Releases](https://github.com/NOTyeamu/Distant-Console-Public/releases)
2. Поместите в любую папку
3. Запустите

При первом запуске потребуется:
- Логин и пароль от ирбис-дистант
- Код приглашения (получить можно на почту ниже)

## Требования

- Windows 10/11
- **Google Chrome** или **Microsoft Edge** (программа использует установленный браузер)
- Если Chrome/Edge не установлен — программа автоматически скачает Chromium (первый запуск займёт больше времени)

## Использование

1. Запустите `Distant.exe`
2. Введите логин и пароль от ирбис-дистант
3. Введите код приглашения (при первом запуске)
4. Выберите режим работы (упрощённый рекомендуется)
5. Выберите курс → выберите тест → выберите режим прохождения
6. Программа заполнит и отправит тест автоматически
